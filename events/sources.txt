# One source per line: how to read it, its URL, a category (music, film or art), and a name. public=no at the
# end keeps a source off the public page (Boston, Daily), for one that isn't ours to republish. Some readers
# sort a source's listings into other categories themselves, like the MFA's films.
# How to read it:
#   aeg        an AEG Presents venue's events.json (Roadrunner)
#   axs        an AXS venue site's full listing page, /events/all, with door times (The Sinclair)
#   ticketweb  a venue page with TicketWeb's event listing (The Middle East)
#   jsonld     a page with schema.org Event data in it (the Brattle's Coming Soon page, House of Blues, a
#              venue's page on DICE)
#   coolidge   the Coolidge Corner Theatre's showtimes page
#   ticketmaster  a Ticketmaster venue id in place of the URL (the Paradise); needs the TICKETMASTER_KEY secret.
#                 Find a venue's id with Actions → "Find a Ticketmaster venue" on GitHub.
#   alamo      an Alamo Drafthouse market's schedule JSON (Boston, which is the Seaport)
#   landmark   a Landmark Theatres theater id in place of the URL (Kendall Square)
#   hfa        the Harvard Film Archive's calendar page
#   frenchlibrary  the French Library's upcoming events page: its screenings, talks and exhibitions
#   ica        the ICA's calendar page: its concerts, screenings, talks, dance and First Fridays
#   veezi      a theater site hosted by Veezi, from the showtimes its pages load (West Newton Cinema)
#   ics        an iCalendar feed (Midway Cafe's, from its Tockify calendar)
#   tribe      a WordPress site's The Events Calendar API, /wp-json/tribe/events/v1/events, optionally with
#              ?categories=<slug> to keep one kind of event (Lizard Lounge, The Rockwell, SoWa)
#   mit        MIT's events calendar API, kept to public exhibitions and arts and humanities talks
#   bibliocommons  a library's BiblioCommons events feed, with ?types=<type ids> for the kinds of event wanted
#              (the ids are in the "eventTypes" data on its events page, bpl.bibliocommons.com/v2/events)
#   mfa        the MFA's program calendar: its lectures, special events and films
#   harvardart Harvard Art Museums' calendar: its lectures, talks, seminars, performances and films
