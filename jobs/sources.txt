# One source per line: how to read it, its URL, the city its jobs are in, and the board's name.
# How to read it:
#   builtin    a Built In metro site (builtinboston.com), whose job pages its robots.txt allows: the cards
#              on each category page in BUILTIN_PAGES (jobs/build.py) — engineering, design, product,
#              data and content
#   wwr        We Work Remotely's feed for a category
#   remoteok   Remote OK's JSON of its latest jobs
#   remotive   Remotive's JSON of its latest jobs
#   madgex     a board running Madgex (Inside Higher Ed, the Chronicle of Higher Education): its RSS for
#              each of MADGEX_QUERIES, since its feed only answers a keyword search
#   techjobs   Tech Jobs for Good's listing pages, for non-profit and public-good work
#   jibe       a university board on Jibe (Tufts): its own JSON, for each of UNIVERSITY_QUERIES
#   silkroad   a university board on SilkRoad (BU): its panels, which carry no dates, so those jobs are
#              dated by the day this board first saw them
#   workday     a board on Workday (universities, hospitals): its own JSON, asked by POST
#   greenhouse an employer's own Greenhouse board, which Greenhouse publishes as JSON
#   usajobs    the federal government's board, which answers by key (USAJOBS_KEY, USAJOBS_EMAIL)
# A city is one of the metros in CITIES (jobs/build.py), "remote" for jobs with no place of work, or
# "anywhere" for a board whose jobs are all over the country, each listing's own place deciding its metro.
# Only jobs whose titles match keywords.txt are kept, whatever the source.
